# Portfolio Brief

## Purpose

This portfolio is for entry-level / junior roles across:

- software development
- IT
- AI engineering
- security / information protection
- infrastructure / cloud-security adjacent roles

It should demonstrate:

1. ability to understand a service
2. ability to build or structure features
3. ability to validate behavior
4. awareness of security and operational risk
5. ability to document decisions accurately

The portfolio should not attempt to portray the candidate as a senior specialist.

---

# Concept

Evidence-led Editorial Portfolio

Keywords:

- quiet
- precise
- editorial
- technical
- evidence
- systems
- credible

Avoid:

- AI SaaS template
- cyberpunk security design
- glassmorphism-heavy visual
- neon
- excessive gradients
- huge cards everywhere
- skill bars
- meaningless metrics
- stock illustrations
